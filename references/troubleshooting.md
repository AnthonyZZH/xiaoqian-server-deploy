# 排错手册（真实踩过的坑）

格式：现象 → 根因 → 解法。

## 微信 / 面板

| 现象 | 根因 | 解法 |
|---|---|---|
| 不发送测试一直 `failed`，读不到消息 | 装的是微信 3.9；适配器只认 4.x（`mmui::MainWindow`） | 卸 3.9，装官网 4.x（静默安装 `/S`），关自动更新 |
| `消息区域被遮挡或收发方向无法确认，暂停这一轮` | 别的窗口（NapCat 控制台、资源管理器、面板自己的弹窗）盖住了聊天区 | server 分支会自动置顶微信并最小化遮挡窗口；偶发一轮可忽略 |
| 截图全黑 / `screen grab failed` | 远程桌面断开或手机 App 退到后台，会话不再渲染 | `08b` 注册断开自动 tscon；手动 `08c-console-now.ps1`；用完 RDP 要真正"断开" |
| 点「开始」没反应、日志一条都没有 | 同上：一开始就截屏失败；或面板进程已崩 | 先 `08c` 切控制台；看 `crash.log`；看门狗会重拉 |
| 一开始就"模型有问题"，每轮 `social_model_failed` | 历史有条数上限、从前面截断，旧版滚动摘要校验认为"历史被改写"永久报错 | server 分支已修（按最后一条已摘要消息重新对齐） |
| DeepSeek 返回空白，不是 JSON | 长的纯文本历史把模型带出 JSON 模式 | server 分支在请求末尾追加"只输出 JSON"的提醒 |
| 面板报错只显示 `social_event` | 旧加固把错误都打码了 | server 分支面板显示真实原因（日志仍只记代码） |
| 让她"去饭友群说…"，回"请写完整名称" / 说自己"没有权限" | 旧版要求精确群名，提示词还写了"没有转告权限" | server 分支由模型理解口语+名字重合兜底；主人私聊提示词改为"系统会替你发" |
| 转告到群里的话带着"主人主人，我这就去…" | 生成转告内容时模型以为在回主人 | server 分支要求"直接对那个聊天的人说"，含"主人"会重写 |
| "给张哥发消息"找不到人 | 群成员在小号眼里是**微信昵称**，不是你手机上的备注；外号记在记忆的人物事实/群黑话里 | server 分支把记忆里的昵称/黑话和群成员目录交给模型；找不到再用微信自己的 @ 成员列表搜 |
| 微信突然"你已退出 WeChat" | 小号在别处登录（同一时间只能一台电脑） | 在服务器上点「我知道了」→「登录」，通常不用手机确认 |
| 面板进程硬崩溃，没有任何错误 | UI 自动化底层（COM）崩溃 | `run_panel.py` 把现场写进 `logs\crash.log`；看门狗 5 分钟内重拉 |

## QQ / NapCat

| 现象 | 根因 | 解法 |
|---|---|---|
| NapCat 启动卡住 | 手动开着的 QQ 占着 | 结束 QQ 和卡住的 launcher 再启动 |
| `MSVCP140.dll` 缺失 | 没装 VC++ x64 运行库 | 装微软官方 VC_redist.x64（核对签名） |
| NapCat 控制台不动了，标题显示"选择" | 鼠标点了控制台进入 QuickEdit 选择模式 | 按 Esc；以后别点它 |
| WebUI 令牌改了不生效 | 配置只在 NapCat 启动时读取 | 重启 NapCat 后再验证旧令牌被拒 |

## 云 / 网络

| 现象 | 根因 | 解法 |
|---|---|---|
| 控制台安全组出方向规则保存失败 | 控制台表单问题 | 改用 Windows 防火墙出站拦截（`03` + `05`） |
| 通过 ssh 管道传密钥后密钥不对 | PowerShell 管道编码把内容改了 | 密钥用 scp 传文件，读出写入环境变量后删除临时文件 |
| 远程桌面连不上 | 家里公网 IP 变了 / 手机用的流量 | 改安全组来源 IP；手机连家里 Wi-Fi；应急用阿里云「云助手」 |

## 从 SSH 调试桌面程序

- SSH 会话没有桌面：截屏、UI 自动化都要用 `10a-run-in-desktop.ps1`（一次性交互计划任务）。
- 想看程序卡在哪：用 `faulthandler.dump_traceback_later(20, repeat=True, file=...)` 包一层启动（只记代码位置）。py-spy 在这里读不了进程内存（error 299）。
- 从 bash 往服务器写含中文的脚本，用文件 + scp，别用 heredoc 管道（会被代码页改坏）。
